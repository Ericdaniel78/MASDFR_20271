# Rúbrica de prácticas

**Matemáticas Actuariales para Seguro de Daños, Fianzas y Reaseguro** · Facultad de Ciencias, UNAM

Esta rúbrica es **reutilizable**: se aplica igual a todas las prácticas del curso. Cada práctica se califica sobre 100, repartidos en cinco criterios. Los pesos pueden ajustarse por práctica si alguna carga más de un lado.

| Criterio | Peso |
|---|---:|
| Correctitud técnica | 35 % |
| Justificación y criterio actuarial | 20 % |
| Código reproducible | 20 % |
| Entrega correcta | 15 % |
| Orden y presentación | 10 % |
| **Total** | **100 %** |

Cada criterio se evalúa en tres niveles: **Destacado**, **Satisfactorio** e **Insuficiente**.

---

## 1. Correctitud técnica — 35 %

*El ajuste, la simulación o el cálculo actuarial está bien hecho.*

| Nivel | Descripción |
|---|---|
| **Destacado** | Los métodos son correctos y apropiados; los resultados son coherentes y bien interpretados; maneja bien los casos delicados (colas, transformaciones, dispersión). |
| **Satisfactorio** | El procedimiento es correcto en lo esencial, con algún error menor o una decisión discutible que no invalida el resultado. |
| **Insuficiente** | Errores técnicos que cambian el resultado, método inadecuado para el problema, o resultados incoherentes sin advertirlo. |

## 2. Justificación y criterio actuarial — 20 %

*Eligieron y explicaron; no solo corrieron código.*

| Nivel | Descripción |
|---|---|
| **Destacado** | Justifican cada decisión (distribución, parámetros, transformaciones) con argumento técnico y lectura actuarial; conectan los resultados con el producto/nota técnica. |
| **Satisfactorio** | Justifican las decisiones principales, aunque de forma breve o incompleta. |
| **Insuficiente** | No hay justificación: se limitan a mostrar salidas sin explicar por qué ni qué significan. |

## 3. Código reproducible — 20 %

*Corre de principio a fin, ordenado y comentado.*

| Nivel | Descripción |
|---|---|
| **Destacado** | El notebook corre completo sin errores; está ordenado, comentado y con nombres claros; cualquiera puede reproducirlo. |
| **Satisfactorio** | Corre con ajustes menores o tiene partes poco comentadas/ordenadas. |
| **Insuficiente** | No corre de principio a fin, depende de pasos manuales no documentados, o es ilegible. |

## 4. Entrega correcta — 15 %

*Por Pull Request, en tiempo y con la estructura pedida.*

| Nivel | Descripción |
|---|---|
| **Destacado** | Entrega por Pull Request en tiempo, con la estructura de carpetas y el título correctos; sin archivos basura ni datos pesados. |
| **Satisfactorio** | Entrega por PR pero con detalles de forma (estructura, nombres, algún archivo de más) o con retraso menor. |
| **Insuficiente** | Fuera del flujo (no es un PR), fuera de tiempo, o con la estructura tan desordenada que dificulta la revisión. |

## 5. Orden y presentación — 10 %

*Legible, con conclusiones claras.*

| Nivel | Descripción |
|---|---|
| **Destacado** | Presentación clara y profesional; incluye conclusiones que responden a lo que pedía la práctica. |
| **Satisfactorio** | Legible, pero con conclusiones débiles o presentación mejorable. |
| **Insuficiente** | Desordenado, sin conclusiones o difícil de seguir. |

---

## Cómo se calcula

Para cada criterio se asigna el nivel logrado, con estos valores de referencia:

- **Destacado** = 100 % del peso del criterio.
- **Satisfactorio** = 70 % del peso del criterio.
- **Insuficiente** = 30 % del peso del criterio (o 0 si no se entregó).

**Ejemplo:** un equipo con Correctitud *Destacado* (35), Justificación *Satisfactorio* (14), Código *Destacado* (20), Entrega *Satisfactorio* (10.5) y Presentación *Destacado* (10) obtiene **89.5 / 100**.

> Nota: la rúbrica del **proyecto final** (los tres documentos + presentación ejecutiva) es aparte y se comparte más adelante.
